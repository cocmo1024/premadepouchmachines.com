Buyer analysis

Write the protocol before machine completion

Product, materials, sample size, run duration, acceptance limits and retest rules should be agreed before travel or video testing.

Test failure and recovery, not only normal running

Challenge no-product, no-package, jam, reject and utility-loss conditions. Confirm alarms, safe states and restart without mixing rejected output.
