Buyer analysis

Case pattern must be physically stable

Pack flexibility, trapped air and orientation affect collation and insertion. Define the case pattern using real filled packs before layout is frozen.

Specify the reject and recovery path

A case line needs rules for missing packs, bad labels, open flaps and downstream blockage. Recovery should not allow rejected product to rejoin good output.
